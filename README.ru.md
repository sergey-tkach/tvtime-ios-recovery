# TV Time iOS Recovery

Восстановление истории просмотров TV Time из локальной резервной копии iPhone или iPad после закрытия
сервиса.

Серверы TV Time выключены, но приложение хранило на телефоне кэш того, что загружало последним: ваши
сериалы со статусами, прогресс по сериям, недавно просмотренные серии и фильмы. Этот инструмент находит
кэш в резервной копии Finder, «Устройств Apple» или iTunes, расшифровывает его и выдает:

- страницу с постерами для просмотра (`TVTime.html`);
- таблицы (`series.csv`, `episodes.csv`, `movies.csv`) и `library.json`;
- готовый файл импорта для [Simkl](https://simkl.com) (`simkl_import.csv`).

Один файл на Python без зависимостей. Работает без интернета и не меняет резервную копию.
English version: [README.md](README.md).

## Прежде чем начать

- Нужно, чтобы **TV Time еще был установлен** на iPhone, или чтобы была локальная копия, сделанная, пока
  он был установлен. Если приложение удалено, кэша больше нет.
- Не удаляйте, не переустанавливайте приложение и не выходите из аккаунта, пока не сделана копия.
- Копия в iCloud не подойдет, нужна копия на компьютере.

## 1. Сделайте резервную копию на компьютер

**Mac:** подключите iPhone, откройте Finder и выберите iPhone в боковой панели. На вкладке «Основные»
выберите «Создавать резервные копии всех данных iPhone на этом Mac» и нажмите «Создать резервную копию
сейчас».

**Windows:** установите приложение «Устройства Apple» (или iTunes), подключите iPhone, выберите
резервное копирование на этот компьютер и создайте копию.

Подходят и зашифрованные, и незашифрованные копии. Для зашифрованной понадобится ее пароль. Дождитесь
окончания копирования.

## 2. Установите Python и скачайте скрипт

- Нужен Python 3.9 или новее. На Mac проверьте в Терминале командой `python3 --version`; если его нет,
  установите с [python.org](https://www.python.org/downloads/). На Windows — с python.org или из
  Microsoft Store.
- Скачайте [`tvtime_recover.py`](tvtime_recover.py) (на GitHub кнопка *Download raw file*), например в
  «Загрузки».

## 3. Запустите

**Mac** (Терминал):

```bash
cd ~/Downloads
python3 tvtime_recover.py
```

**Windows** («Командная строка»):

```bat
cd %USERPROFILE%\Downloads
py tvtime_recover.py
```

С Python из Microsoft Store пишите `python` вместо `py`.

Скрипт найдет копию, спросит пароль, если она зашифрована, сохранит результат в новую папку
`TVTime-Recovery-<дата>` в текущей папке и откроет страницу в браузере.

### macOS: «Терминал не может прочитать папку с копиями»

macOS не дает приложениям читать `~/Library/Application Support/MobileSync`. Есть два пути:

1. **Скопировать копию (проще).** Finder → iPhone → «Управлять резервными копиями…» → правый клик по
   копии → «Показать в Finder». Выделите папку с длинным именем, нажмите ⌘C, откройте, например,
   «Документы» и нажмите ⌘V. На том же диске копия создается мгновенно и не занимает места. Затем:

   ```bash
   python3 tvtime_recover.py --backup ~/Documents/ВСТАВЬТЕ_ИМЯ_ПАПКИ
   ```

2. Или дать Терминалу полный доступ к диску (Системные настройки → Конфиденциальность и безопасность →
   Полный доступ к диску) и перезапустить Терминал.

### Параметры

| Параметр | Что делает |
|---|---|
| `--backup ПАПКА` | Взять эту резервную копию (папку с `Manifest.db`) |
| `--output ПАПКА` | Куда сохранить результат (папки еще не должно быть) |
| `--list-backups` | Показать найденные копии и выйти |
| `--diocache ПУТЬ` | Без копии: прочитать уже извлеченный `DioCache.db` или папку с файлами TV Time |
| `--all-files` | Скопировать в `raw/` и остальные файлы TV Time (там есть токены входа) |
| `--diagnose` | Показать структуру кэша без личных данных, для сообщения об ошибке |
| `--password-stdin` | Прочитать пароль копии из стандартного ввода |
| `--no-open` | Не открывать страницу в браузере |

## Что получится

| Файл | Содержимое |
|---|---|
| `TVTime.html` | Сериалы и фильмы с постерами, фильтр по статусам, поиск, последние серии. Язык — как в браузере: русский или английский |
| `series.csv` | Все отслеживаемые сериалы: статус, просмотрено / вышло серий, последняя и следующая серия, даты, TVDB ID |
| `episodes.csv` | Серии из кэша с датой и временем просмотра |
| `movies.csv` | Фильмы: просмотрен ли, дата, пересмотры, IMDb ID |
| `simkl_import.csv` | Файл импорта для Simkl, см. ниже |
| `library.json` | Всё то же одним структурированным файлом |
| `raw/`, `file_index.csv` | Файлы приложения из копии и их список |

## Что восстанавливается, а что нет

В кэше лежат последние ответы сервера, которые загружало приложение, поэтому все данные — на эту дату
(она указана на странице). В кэше TV Time 10.x, на котором разрабатывался инструмент, нашлись:

- **все отслеживаемые сериалы** со статусом «Смотрю», «Всё просмотрено», «Брошено» или «Не начато», с
  датой добавления и датой последнего просмотра;
- «Всё просмотрено» значит, что просмотрены все серии, вышедшие к той дате, то есть прогресс по таким
  сериалам полный;
- счетчики «просмотрено / вышло» и следующая серия для сериалов из списков «Продолжить просмотр» и
  «Давно не смотрели»;
- недавно просмотренные серии с точным временем и просмотренные фильмы с датами.

Чего обычно **нет** в кэше: дат просмотра старых отдельных серий, точной позиции в сериалах «Смотрю», не
попавших в эти списки, оценок, комментариев и пользовательских списков.

Старые версии приложения кэшировали другие ответы, в некоторых есть полная поэпизодная история.
Инструмент понимает и старые форматы, описанные в tvtime-backup-extractor. Они покрыты тестами на
выдуманных данных, но на настоящей старой копии пока не проверялись.

## Перенос в Simkl

1. Войдите в Simkl и откройте [simkl.com/apps/import/csv](https://simkl.com/apps/import/csv/).
2. Выберите `simkl_import.csv`, оставьте *Use .csv data* и нажмите *Upload and start import*.

| TV Time | Simkl |
|---|---|
| Смотрю | watching, с последней просмотренной серией, если она известна |
| Всё просмотрено | completed |
| Брошено | dropped |
| Не начато | plan to watch |
| Просмотренный фильм | completed, с датой просмотра |

Сериалы сопоставляются по TVDB ID (ID сериалов в TV Time — это ID TheTVDB), фильмы по IMDb ID. Столбцы
файла — по документации Simkl. Для других сервисов отталкивайтесь от `library.json` или CSV.

## Приватность

- Всё работает на вашем компьютере, ничего никуда не отправляется. Страница при открытии загружает
  постеры с artworks.thetvdb.com.
- Резервная копия открывается только на чтение. Пароль используется только в памяти.
- В `raw/` лежит кэш приложения, а в нем — токены входа в TV Time. Серверы выключены, но папку лучше
  никому не передавать. Для сообщений об ошибках годится только вывод `--diagnose`: в нем имена полей и
  количества, без названий, дат и ID.

## Если что-то не так

| Сообщение | Что делать |
|---|---|
| No backup with TV Time found | Сделайте локальную копию (шаг 1) или укажите `--backup` |
| macOS не дает прочитать папку с копиями | См. раздел про macOS выше |
| Wrong backup password | Нужен пароль шифрования локальных копий, а не пароль Apple ID |
| TV Time is not in this backup | Приложение не было установлено, когда делалась копия |
| No TV Time library data was recognized | Запустите с `--diagnose` и создайте issue с этим выводом |
| Расшифровка идет медленно | Быстрая библиотека AES не нашлась, и индекс копии расшифровывается на чистом Python (около 1 МБ/с). Это займет несколько минут |

Если пароль копии забыт, Apple предлагает сбросить все настройки на iPhone (Настройки → Основные →
Перенос или сброс iPhone → Сброс → Сбросить все настройки). Пароль копии снимется, приложения и данные
останутся, но сбросятся, например, сети Wi-Fi и обои. После этого сделайте новую копию.

## Как это устроено

1. **Резервная копия.** `Manifest.db` — индекс всех файлов копии. В зашифрованной копии он зашифрован
   AES; его ключ обернут ключом класса из keybag в `Manifest.plist`. Ключи классов открываются паролем:
   медленный раунд PBKDF2-SHA256 (с iOS 10.2), затем PBKDF2-SHA1, затем развертка ключа AES по RFC 3394.
   У каждого файла свой обернутый ключ AES-256-CBC. Базы SQLite iOS сохраняет свежим снимком, поэтому
   их размер в индексе бывает неверным; настоящую длину дает паддинг PKCS#7.
2. **Кэш.** TV Time — приложение на Flutter. `Documents/DioCache.db` — HTTP-кэш в SQLite: таблица
   `cache_dio`, по ответу сервера в JSON на строку. Старые версии держали еще NSKeyedArchiver-файлы с
   URL запроса и JSON ответа.
3. **Библиотека.** Инструмент объединяет все распознанные ответы: списки отслеживаемых сериалов,
   прогресс по сериалам (`shows`), сезоны из профиля, списки серий (история, «далее»), фильмы и события
   просмотра. Данные чужих аккаунтов (профили друзей, которые приложение тоже закэшировало) отбрасываются.

AES берется из системной CommonCrypto на macOS, из OpenSSL, который идет вместе с Python на Windows и
Linux, или из запасной реализации на чистом Python. Перед использованием каждая проходит тесты на
известных векторах.

## Разработка

```bash
python3 -m unittest discover -s tests -v
```

Тесты используют только выдуманные данные. Чтобы проверить другие реализации AES, задайте
`TVTIME_AES_BACKEND=pure-python` или `TVTIME_AES_BACKEND=openssl` вместе с
`TVTIME_LIBCRYPTO=/путь/к/libcrypto`. Никогда не добавляйте в репозиторий настоящие копии, кэши и
результаты восстановления.
